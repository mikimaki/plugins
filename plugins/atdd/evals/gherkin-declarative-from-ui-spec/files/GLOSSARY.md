# Glossary

- **Listener**: a person using the app to play podcasts. Never "user" in domain language.
- **Episode**: one audio file of a podcast.
- **Playback**: the episode currently playing, with its position.
- **Sleep timer**: a countdown that ends playback when it runs out.
- **Timer duration**: the length of a sleep timer, in whole minutes.
- **Queue**: the episodes lined up to play next.
